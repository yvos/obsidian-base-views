# PLAN-20260214 Basesビュー一覧UX改善

## 目的
- Bases view一覧の可読性と操作性を高める。
- 将来の分離を意識しつつ、配置切替・情報表示・サイズ制御を強化する。

## 実装タスク
- [x] closeアイコンを小型化
- [x] 左配置ヘッダーを「ビュー」から baseファイル名（拡張子除く）へ変更
- [x] view名の左寄せレイアウトに統一
- [x] フォントサイズ設定（M/S/XS）を追加
- [x] viewプロパティ表示設定（表示ON/OFF + プロパティキー）を追加
- [x] プロパティ値がリストのときにカンマ区切りで表示
- [x] プロパティ値が空のときは2行目を非表示
- [x] 左配置時の自動幅短縮（保存幅が初期値時のみ）を追加
- [x] 配置モード設定（left/top）を追加
- [x] 右クリックコンテキストメニューで left/top を切替可能化
- [x] top配置では `bases-header` 直下挿入、タイトル非表示（closeのみ）
- [x] 既存仕様（1view非表示、開閉、増殖防止、resizer）維持
- [x] i18n（ja/en）追加
- [x] 単体テスト拡張
- [x] 実装/ログ文書更新

## 受け入れ条件
- 左配置ではヘッダーに baseファイル名が表示され、top配置ではタイトルが非表示になる
- view名は左寄せで、プロパティ行が設定に応じて表示/非表示される
- フォントサイズ設定で M/S/XS が反映される
- 右クリックメニューと設定の両方で配置切替できる
- 保存幅が初期値のときのみ自動幅短縮が効く
- 1viewのbaseで一覧UIとトグルは表示されない
- refresh/設定変更連打でも一覧が増殖しない

## 検証制約
- 現環境は `node` / `npm` が存在しないため、`npm test` / `typecheck` / `build` は未実行になりうる。
- Obsidian CLI 実行制約がある場合は LOG に未実施理由を残す。
