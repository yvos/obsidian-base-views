# PLAN-20260214 Basesビュー一覧増殖修正

## 目的
- Base view切替や別`.base`表示時に、view一覧サイドバーが重複増殖する不具合を解消する。
- 常に1つの一覧レイアウトだけが存在する状態を保証する。

## 実装タスク
- [x] 増殖再現経路の特定（`ensureManagedLayout` / `cleanupLeaf`）
- [x] レイアウト正規化処理の追加（不正な入れ子ラッパーの解除）
- [x] 既存レイアウト再利用ロジックの強化（root判定の安定化）
- [x] cleanup処理の堅牢化（親不一致でも復元・撤去）
- [x] 再発防止テスト追加（反復refreshで増殖しないこと）
- [x] LOG更新

## 受け入れ条件
- 同一leafでview切替を繰り返しても `.tn-bases-view-list-layout` は1つのまま
- `.base` を開き直しても一覧が横に増えない
- 設定変更イベント連打でも一覧が増殖しない

## 検証制約
- `npm` 未導入環境のため、単体テストの実行は未完了（テストケース追加のみ）。
