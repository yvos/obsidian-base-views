# Base Views Privacy Policy

Last updated: March 4, 2026

## Overview

Base Views is an Obsidian plugin that enhances view operations for `.base` files.

## Data Collection and Usage

Base Views does not collect, transmit, or share any of your data.

## Data Storage

- All data remains local to your Obsidian vault
- Plugin settings are stored locally in Obsidian's configuration
- No data is sent to external servers or third parties

## Network Requests

Base Views does not make any network requests. All features operate entirely offline and locally.

## Data Deletion

You can delete your data at any time:
- Disable the plugin to stop all plugin processing
- Remove the plugin to delete all plugin settings
- Your notes remain in your Obsidian vault under your control

## TaskNotes Runtime Integration

If you use `Task List View (Custom)` with the TaskNotes plugin installed, behavior of TaskNotes-enabled features follows [TaskNotes' privacy policy](https://github.com/calluma/tasknotes). Base Views itself does not control or access any data handled by TaskNotes.

## Changes to Privacy Policy

We may update this policy. Changes will be posted in this file with an updated date.

## Contact

For questions or concerns about privacy, please open an issue on GitHub:
- https://github.com/iiz00/obsidian-base-views/issues

## Open Source

Base Views is open source software. You can review the code at https://github.com/iiz00/obsidian-base-views to verify these privacy practices.
