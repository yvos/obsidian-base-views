## [0.1.0] - 2026-03-05

### Added
- View list sidebar: always shows the view list for `.base` files with multiple views
- Table View (Custom): Bases table view with unnest support for multi-value properties and two-level grouping
- Task List View (Custom): based on TaskNotes Task List view, with unnest support for multi-value groups
- Iconic plugin integration for file icons in Table View (Custom)

### Notes
- Based on a fork of [TaskNotes](https://github.com/callumalpass/tasknotes) by Callum Alpass
- Requires Obsidian 1.10.1 or later (Bases feature dependency)
